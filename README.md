Projeto pessoal para fins de estudo: Analise de dados com tabela interativa para analisar dados em um arquivo CSV
# 📊 Leitura e Análise de Dados CSV (com Pandas)

Programa em Python que lê um arquivo **CSV de vendas** e permite analisar as informações por meio de um menu interativo no terminal.

Ele oferece opções para visualizar os dados completos ou filtrar colunas específicas — além de calcular estatísticas simples sobre as vendas.

---

## 🛠️ Tecnologias

- Python 3.x  
- Pandas  
- Colorama (cores no terminal)
